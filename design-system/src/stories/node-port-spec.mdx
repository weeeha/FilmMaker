# Node Port — sizes & spaces

Spec for the connection port (Figma: "Port / *"). All port types share the same
geometry; only the color treatment differs. Documented here for the **Text**
and **Avatar** ports; the other blue ports match Avatar.

## Shared geometry

<table>
  <thead>
    <tr><th>Property</th><th>Value</th><th>Token</th></tr>
  </thead>
  <tbody>
    <tr><td>Port diameter</td><td>28 × 28 px</td><td><code>--spacing(7)</code></td></tr>
    <tr><td>Shape</td><td>full circle</td><td><code>--radius-full</code></td></tr>
    <tr><td>Border width</td><td>1 px</td><td>default border (no token)</td></tr>
    <tr><td>Icon size</td><td>14 × 14 px</td><td><code>--spacing(3.5)</code></td></tr>
    <tr><td>Icon inset</td><td>7 px all sides</td><td>derived — (28 − 14) / 2, icon centered</td></tr>
    <tr><td>Icon stroke</td><td>2 units @ 24 viewBox ≈ 1.17 px rendered</td><td>lucide default</td></tr>
    <tr><td>Shadow</td><td>0 / 1 / 1, black 6%</td><td><code>0px 1px 1px rgba(0,0,0,0.06)</code> — no shadow token</td></tr>
  </tbody>
</table>
