# Voice Changer node

The Voice Changer node transforms speech from a source audio file into a
selected voice. It preserves the original performance's timing, emotion,
accent, and delivery, including nuances such as whispers and laughter. The
node outputs the transformed speech as audio.

_Source: ElevenLabs Voice Changer._

## Anatomy

Header with active model, audio preview, target-voice prompt row with Run.
Below the card sits the node menu pill with the node's settings and actions.
