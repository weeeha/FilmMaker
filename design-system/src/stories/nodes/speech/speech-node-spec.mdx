# Text to Speech node — spec

## Description

The Text to Speech node converts text into lifelike spoken audio using a
selected voice and speech model. It interprets textual cues to shape
intonation, pacing, and emotional delivery. The generated speech audio can be
passed to a compatible downstream node.

_Source: ElevenLabs Text to Speech._

## Rules

- The node has one text input port, aligned with the text area, and one audio output port aligned with the preview strip.
- The text can be typed directly or supplied by an upstream text connection.
- The voice is chosen in the voice row; the model is chosen in the node menu.
- Its output must connect to a compatible audio input on another node.
