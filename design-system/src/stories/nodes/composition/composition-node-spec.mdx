# Composition node — spec

## Description

The Composition node provides a centralized preview where users can layer
connected video and audio outputs. It combines video, speech, music, and
sound effects so the complete result can be reviewed in one place. The node
does not generate content on its own.

_Source: ElevenCreative Flows._

## Rules

- The node has video and audio input ports aligned with their track rows, and one video output port aligned with the preview top.
- Tracks can be added with the add-track row; each track has volume and mute controls.
- It is normally the final node of a flow.
- Its output can be exported or connected to a compatible video input.
