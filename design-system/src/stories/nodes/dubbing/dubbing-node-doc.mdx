# Dubbing node

The Dubbing node translates speech from a connected video source into a
selected target language. It preserves each speaker's voice characteristics,
emotion, timing, and tone while retaining the original background audio. The
node outputs the dubbed video.

_Adapted from ElevenLabs Dubbing to match the current implementation._

## Anatomy

Header with active model, source area (empty until a source is connected), Run row.
Below the card sits the node menu pill with the node's settings and actions.
